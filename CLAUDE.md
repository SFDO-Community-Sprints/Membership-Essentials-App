## Claude Code

Claude Code reads `CLAUDE.md` rather than `AGENTS.md`, so this file exists only to import it — the instructions themselves live in one place. Contributors on other tools read `AGENTS.md` directly.

The contribution loop for this project is packaged as a skill in `.claude/skills/metecho-local/`, discovered automatically inside this repository.

Prefer plan mode before editing anything under `force-app/main/default/flows/`: flow metadata is generated by Flow Builder, and a hand-edited flow is harder to review than the change it carries.
